## アプリケーションの概要

Fitノートは、日々のトレーニング記録を管理するWebアプリケーションです。

トレーニングの日付や種目、重量、回数、セット数に加え、時間・速度・傾斜などを記録できます。
記録の一覧表示や編集、削除にも対応しており、日々のトレーニングを振り返ることができます。

## 開発した背景

筋力トレーニングの内容を記録し、日々のトレーニングを振り返りながら管理できるようにするために開発しました。

## 主な機能

- トレーニング記録の登録
- トレーニング記録の一覧表示
- トレーニング記録の編集
- トレーニング記録の削除
- トレーニング種目の追加
