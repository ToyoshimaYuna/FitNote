# Fitノート

## アプリケーションの概要

Fitノートは、日々のトレーニング記録を管理するWebアプリケーションです。

トレーニングの日付、種目、重量、回数、セット数などを登録し、記録を一覧で確認できます。

## 開発した背景

筋力トレーニングの内容を記録し、日々のトレーニングを振り返りながら管理できるようにするために開発しました。

## 主な機能

- トレーニング記録の登録
- トレーニング記録の一覧表示
- トレーニング記録の編集
- トレーニング記録の削除
- トレーニング種目の追加
